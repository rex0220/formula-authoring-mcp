# 計算パターン（やりたいこと → やり方）

計算式を設計する前に、目的の言葉（集計、小計、行番号、転記、初期、分類、割合、累計、日付、ユーザー …）でこの文書を検索する。同じ目的に 2 つ以上のやり方があるものは、結果の違いを利用者に示して選んでもらう（[AI作業手順.md](AI作業手順.md) の「仕様の確認」）。
式の例は、テスト用アプリ（2305 テーブル内集計、4328 出張管理）か関数一覧の使用例で動かして確かめたもの。記事の欄の ✔ は、tools に同梱のサンプルアプリと架空の値で計算式エンジンに評価させて確かめた例（結果は [計算パターン_検証.md](計算パターン_検証.md)。エンジンの版が変わるたびに作り直す）。関数の引数は [関数一覧.md](関数一覧.md)。記事は `https://qiita.com/rex0220/items/<番号>`（利用者に案内するとき）。

## 前提（テーブルの式の読み方）

- テーブルの**外**の式では、テーブル内項目を**そのまま書くと 1 行目の値**になる（`ARRAY_GET(金額, "last")` は最後の行の値にならない。2026-10-18 に `fml_try` で確認）。全行を見るのは集計・テーブルの関数（`SUM(金額)` は全行の合計、`LAST(金額)` は最後の有効な値、`FIRST` / `LASTIF` / `TDS(金額)` は重複を除いた配列）。テーブルの**中**（テーブル内項目に置いた式）では、その項目は**その行の値**で、集計関数（SUM / SUMIF / COUNTIF / LASTIF …）は全行を見る
- テーブル内項目の式は行ごとに動く。`ROWNO(テーブル)` が今の行（0 始まり）。前の行だけを見るには `ROWNO(テーブル) < CNO` のような条件を集計関数に付ける（`LET(CNO, ROWNO(テーブル), …)`）
- ランクなしの計算順は、テーブルの外（1 回目）→ テーブルの中（左から右）→ テーブルの外（2 回目）。この順で合うならランクは付けない
- テーブル自身に式を置くと**行数の制御**になる（計算式プラグインの記事「テーブルの設定」）。式の結果で:
  - 空文字 → 何もしない
  - 数値 → その行数にする（設定画面の「既存レコードを変更」は 0〜100、画面は 0〜500。100 行以上は表示が遅い）
  - JSON の文字列 → 新規レコードのときの初期の行。引用符は `"` でなく `'`（例 `"[{'日付':'2026-01-19','分類':'鉄道','金額':'393'},{'日付':'2026-01-03','分類':'バス','金額':'230'}]"`。`OTVAL` 関数で作れる）
  - 配列 `ARRAY(行数, 初期の行の文字列, 更新のタイミング)` → 行数は `""` で処理なし、タイミングは 0 = 追加のときだけ（既定）、1 = 追加と更新のとき
  - `TLTABLE` / `TABLE_DATA` / `TABLE_SORT` の結果（テーブルの形）→ その行にする
  - テーブルの行の追加・削除ボタンは出なくなる（編集のチェックが無いとき）

## 空・比較・端数の決まり（どの式にも効く。2026-10-18 に検証）

| 決まり | 例（結果） | 注意 |
| --- | --- | --- |
| 空の数値を計算すると空のまま | `数値1 + 1`（空 → 空、2.5 → 3.5） | 0 にしたいなら `NVL(数値1, 0) + 1` |
| 空との比較は偽。空の判定は `= ""` / `ISBLANK` / `NOT` | `数値1 > 0`（空 → 偽）、`ISBLANK(数値1)`（空 → true）、`ISBLANK(数値1, 数値2)`（全部空で true） | `IF(項目, …)` は **0 も偽** |
| ゼロ除算は空（エラーにならない） | `1 / 数値2`（0 → 空） | — |
| **比較は、両方が数に見えれば数として、そうでなければ文字順** | `"2" > "10"` は偽（数として 2 < 10）、`"2" > "10a"` は真（文字順で `"2"` > `"1"`）、`文字列1 = 2` も数として | 数でない文字に `* 1` を掛けると空になる（`"abc" * 1` → 空）。桁数の違う番号を文字順で並べたいときはゼロ埋めする |
| 端数: `ROUND` は 0 から遠い方へ（2.5 → 3、-2.5 → -3）。`ROUNDDOWN` は 0 へ（-2.5 → -2）、`ROUNDUP` は 0 から遠い方へ（-2.5 → -3）、`INT` は小さい方へ（-2.5 → -3）、`MOD` の符号は割られる数（`MOD(-7, 3)` → -1） | `ROUND(1.005, 2)` → 1.01、`0.1 + 0.2` → 0.3（10 進で計算） | 割り切れない値は 20 桁（`1 / 3 * 3` → 0.99999999999999999999）。割った後は `ROUND(…, 桁)` |

## スペース項目（HTML の表示。レコードに値は残らない）

スペース項目に計算式を置くと、その場所に文字や HTML を表示できる（Ver.44〜。詳細画面でも最新の計算結果を出す）。アプリの設定でスペース項目に**要素 ID** を付けておく。値はレコードに残らないので一覧には出ない。`fml_try` / `try` は同梱のサンプルアプリのスペース項目 `sp1` を対象にできる（`as: "sp1"` か `"SPACER"`。式の返り値 = 配列や HTML をそのまま返す。表示の確かめは実機で）。
