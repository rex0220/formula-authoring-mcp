# 関数一覧（計算式エンジンの説明文から）

計算式プラグイン Ver.102 の計算式エンジンが持つ 250 個の関数。設定画面の「?」と計算式ツールと同じ説明（日本語）。`tools/scripts/gen-docs.mjs` が作る。手で直さない。
関数名で検索して読む（全部は読まない）。印: **副作用**（sideEffect）、**kintone の文脈**（kintoneContext）、**ユーザー情報**（userInfo）、**イベント**（event）、**再計算で変わる**（volatile）。副作用のある関数は tools が評価しない（policy で承認）。EV_SET は設定に入れない。
使用例はエンジンの説明文に同梱のもの（`->` の結果は計算式プラグインの開発時に実際に評価して確かめている。項目や日時に依る例は環境で変わる。tools の gen-docs も評価し、合わない例は [計算パターン_検証.md](計算パターン_検証.md) の末尾に列挙）。

## 説明と使用例（説明文の全文）

### ABS

項目 — 絶対値を返す

```
ABS(数値)
ABS(-1.234) -> 1.234
ABS("1.234a") -> ""
```

### ADD_TAGS

項目 — 文字列複数行項目にタグを追加

ADD_TAGS(文字列複数行)  

```
ADD_TAGS("ABC\nXYZ") -> "&lt;div&gt;ABC&lt;/div&gt;&lt;div&gt;XYZ&lt;/div&gt;"
ADD_TAGS("- ABC\n- XYZ") -> "&lt;ul&gt;&lt;li&gt;ABC&lt;/li&gt;&lt;li&gt;XYZ&lt;/li&gt;&lt;/ul&gt;"
```

### AND

条件[,...] — 論理関数 (論理積)

```
AND(数値1,数値2)
AND(数値1>10,数値2>20)
AND(文字列1="B",文字列2="C")
AND(0,0) -> false
AND(1,0) -> false
AND(1,1) -> true
AND(1,"0") -> true
AND("","0") -> false
```

### APP_URL

[path][,isGuestSpace] — ベースURLを含むURLを生成

path: ベースURLを省略して指定  
isGuestSpace: 0(既定値), 1(ゲストスペース用)  

```
APP_URL() -> "https://xxxxxx.cybozu.com/"
APP_URL("/k/100/?view=1111") -> "https://xxxxxx.cybozu.com/k/100/?view=1111"
APP_URL("/k/200/?view=1111", 1) -> "https://xxxxxx.cybozu.com/k/guest/10/200/?view=1111"
```

### ARRAY

項目[,...] — 指定された値を配列にする

```
ARRAY()
ARRAY(数値1,数値2)
ARRAY(チェックボックス1,チェックボックス2)
ARRAY("A","B") -> ["A","B"]
ARRAY("A","B",ARRAY("C","D")) -> ["A","B","C","D"]
```

### ARRAY_COUNT

項目[,...] — 配列数

```
ARRAY_COUNT(チェックボックス)
ARRAY_COUNT(SEL_CODE(ユーザー選択,"array"))
ARRAY_COUNT(ARRAY("A","B")) -> 2
```

### ARRAY_DEL

項目,項目[,...] — 配列要素を削除

```
ARRAY_DEL(チェックボックス,"sample1")
ARRAY_DEL(チェックボックス1,チェックボックス2)
ARRAY_DEL(ARRAY("A","B"),"A") -> ["B"]
```

### ARRAY_DIC

配列,変数名[,インデックス],式 — 配列をループし、各要素で式を評価し、ディクショナリー(連想配列)を作成します。

式は通常 DIC(キー, 値) の形式を返します。  

```
ARRAY_DIC(ARRAY(1,2,3), vn, DIC(vn, 1)) -> {"1":1, "2":1, "3":1}
ARRAY_DIC(ARRAY(1,2,3), vn, idx, DIC(vn, idx)) -> {"1":0, "2":1, "3":2}
ARRAY_DIC(ARRAY(DIC("A",1),DIC("B",2)), vn, vn) -> {"A":1, "B":2}
```

### ARRAY_EQUALS

項目,項目 — ２つの配列のすべての要素が等しいか判定

```
ARRAY_EQUALS(ARRAY(1,2,3),ARRAY(1,2,3)) -> true
ARRAY_EQUALS(ARRAY(1,2,3),ARRAY(1,2,3,4)) -> false
ARRAY_EQUALS(ARRAY("A","B","C"),ARRAY("A","B","C")) -> true
ARRAY_EQUALS(ARRAY(1,2,3),ARRAY("A","B","C")) -> false
```

### ARRAY_EVERY

項目,変数名[,インデックス],要素式 — 配列のすべての要素が特定の条件を満たしているか判定

```
ARRAY_EVERY(ARRAY(1,2,3),XX,XX>1) -> false
ARRAY_EVERY(ARRAY(1,2,3),XX,XX>0) -> true
ARRAY_EVERY(ARRAY("A","B","C"),XX,XX!="X") -> true
ARRAY_EVERY(ARRAY(1,2,3),XX,idx,idx>1) -> false
```

### ARRAY_FIL

項目,変数名[,インデックス],要素式 — 配列の要素を式でフィルタリング

```
ARRAY_FIL(ARRAY(1,2,3),XX,XX>1) -> [2,3]
ARRAY_FIL(ARRAY(1,2,3),XX,XX!=2) -> [1,3]
ARRAY_FIL(ARRAY("A","B","C"),XX,XX!="A") -> ["B","C"]
ARRAY_FIL(ARRAY(1,2,3),XX,idx,idx>1) -> [3]
```

### ARRAY_FOR

項目[,インデックス],要素式 — 指定した要素数の配列に変換※最大数 100000

```
ARRAY_FOR(3,idx,idx) -> [0,1,2]
ARRAY_FOR(3,idx,idx*3) -> [0,3,6]
ARRAY_FOR(3,"A") -> ["A","A","A"]
ARRAY_FOR(3,idx,"A"&idx) -> ["A0","A1","A2"]

### ARRAY_GET

ARRAY_GET(ARRAY("A","B"),"first") -> "A"
ARRAY_GET(ARRAY("A","B"),"last") -> "B"
```

### ARRAY_MAP

### ARRAY_SOME

### ARRAY_SORT

### TLTABLE

テーブル,	//TPOPT("MAXROWS",10),	//TPFILTER(集計条件),	TPKEY(テーブル内項目),TPVAL(集計項目),TPOUT(出力先テーブル内項目),	//TPSORT(出力先テーブル内項目),	//TPLABEL("ラベル1","ラベル2"),	 — テーブルの集計関数

TPOUT(出力先テーブル内項目): 出力項目指定

### WHICH

WHICH([ユーザーコード], 条件1, 値1, ..., デフォルト値) — 指定したユーザーが各条件（ユーザー選択・組織・グループ等）に含まれているかを順に判定し、一致した最初の値を返します。

ユーザーコードを省略した場合、ログインユーザーが判定対象となります。  
条件はユーザー選択フィールド、OUSERS/GUSERSなど配列で返すものに対応。  

```
WHICH("user_001", 更新者, 1, ユーザー選択, 1, OUSERS("sales"), 1, OUSERS("dev"), 0, GUSERS("everyone"), 1, 1)
WHICH(ユーザー選択, 100, 0) // ログインユーザーがユーザー選択に含まれていれば100, 含まれていなければ0
```
