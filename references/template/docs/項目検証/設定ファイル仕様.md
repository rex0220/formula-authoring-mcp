# 設定ファイル仕様（項目検証）

<!-- tools/scripts/gen-fv-docs.mjs が作る（tools の src/fv/ の決まりから）。手で直さない -->

項目検証プラグイン（rex0220 field validation）Ver.72 以降の設定ファイルの形です。AI は**封筒 + 元の値**だけを書きます（雛形 [samples/項目検証/settings-source.json](../../samples/項目検証/settings-source.json)）。
設定画面の「設定をダウンロード」のファイルは保存値（派生値・内部番号）も入っていますが、取り込みは元の値だけを使うので、`fv normalize` はそれらを捨てます。

## 封筒

| キー | 値 |
| --- | --- |
| `pluginID` | `"rex0220 field validation plugin"`（違えば取り込めない） |
| `PluginVersion` | 項目検証の版の数の文字列（`"72"` など。72 未満はエラー） |
| `appId` | アプリ番号（数。`fields` のアプリと同じ） |
| `appName` / `pluginName` / `date` | 任意（`fv normalize` の出力では補う） |

## 元の値（封筒と同じ階層）

| キー | 型 | 既定 | 意味 |
| --- | --- | --- | --- |
| `pluginEnable` | true / false | true | プラグインを有効にする |
| `pluginPreHide` | true / false | false | 非表示前処理（非表示の式がある項目を、画面を開いたときに先に隠す。ほかのプラグインと競合するときは外す） |
| `pluginProductEnv` | true / false | false | 設定画面で保存するとき「運用環境に反映」もする |
| `pluginComment` / `pluginDescription` | 文字列 | "" | NOTE（ツールバーの 1 行）/ 説明（「説明」のダイアログ） |
| `pluginBorderInfo` | `{ borderList: [行 × 3 まで] }` | {}（既定の枠線） | 枠線。行は `state` / `btype`（区分の文言）/ `width`（0〜8 の整数）/ `color`（#rrggbb）。順は 1 必須で未入力（既定 5px #ff8000）、2 必須で入力済み（既定 5px #7bd6af）、3 エラー（既定 5px #e74c3c） |
| `pluginInfos` | 行の配列 | [] | 項目ごとの設定（下）。書かない項目は設定なし。フォームで必須の項目は、書かなくても必須条件 `"1"` の行になる |

## 行（`pluginInfos` の要素）

| キー | 型 | 意味 |
| --- | --- | --- |
| `fieldcode` | 文字列 | 行の識別（必須）。項目はフィールドコード、スペース・ラベル・罫線は `"(要素ID)"`、テーブルの行の追加・削除ボタンは `"<テーブル>($ADD)"` / `"<テーブル>($DEL)"`、グループはグループのフィールドコード。同じ行を 2 つ書かない |
| `state` | true / false | 「使う」。オフの行の式は効かない |
| `formulaSet` | 式 | 必須条件（真のとき必須。フォームで必須の項目は `"1"` に固定） |
| `disabledSet` | 式 | 入力不可（真のとき入力できない） |
| `hideSet` | 式 | 非表示（真のとき隠す） |
| `init` | true / false | 初期化（隠れたまま保存するとき初期値に戻す。初期値が空のルックアップは、隠れて値があれば解除する） |
| `condInfos` | 検証条件の配列 | 上から見て、「使う」がオンで条件が真の最初の 1 つのメッセージでエラーにする。キーは `state` / `condSet`（条件の式）/ `jaSet` / `enSet` / `zhSet`（メッセージの式。英・中が空なら日）。オンなら条件とメッセージ（日）は必須 |
| `tblfields` | テーブル内非表示の配列 | テーブルの行だけ。子の列を隠す。キーは `fieldcode`（子）/ `state` / `hideSet`（式）。書かない子は設定なし |

旧い形のキー `formula` / `disabled` / `hide`（行）、`cond` / `ja` / `en` / `zh`（検証条件）も読みます（出力は新しい形）。

## 列ごとに置けない型

| 列 | 置けない型 |
| --- | --- |
| 必須条件 `formulaSet`・入力不可 `disabledSet` | GROUP, SUBTABLE, CALC, REFERENCE_TABLE, SPACER, LABEL, HR, $BUTTON |
| 初期化 `init` | GROUP, SUBTABLE, CALC, REFERENCE_TABLE, SPACER, LABEL, HR, $BUTTON, FILE |
| 検証条件 `condInfos` | GROUP, SUBTABLE, CALC, FILE, REFERENCE_TABLE, SPACER, LABEL, HR, $BUTTON |
| テーブル内非表示 `tblfields` | テーブル（SUBTABLE）の行のほか全部 |
| 非表示 `hideSet` | どの行にも置ける |

行になる型: GROUP, SUBTABLE, CALC, SINGLE_LINE_TEXT, MULTI_LINE_TEXT, RICH_TEXT, NUMBER, DATE, DATETIME, TIME, DROP_DOWN, RADIO_BUTTON, CHECK_BOX, MULTI_SELECT, USER_SELECT, ORGANIZATION_SELECT, GROUP_SELECT, LINK, FILE, REFERENCE_TABLE。要素 ID の行: SPACER, LABEL, HR（要素 ID があるもの）。行のボタン: `$BUTTON`。

## 書かないキー

保存値のキー（`pluginFields`, `pluginPP`, `pluginRecNo`, `pluginStatus`, `pluginStatusCode`, `pluginStatusAssignee`, `pluginHideCheck`, `pluginUOG`）、外枠のキー（`pluginLastUpdate` など）、行の画面・保存のキー（`id` / `type` / `usedFields` / `condDesc` / `fieldno` など）。設定画面が保存のときに作るので書かない（書いてあっても捨てる）。

## 式の決まり

- 項目検証では使わない更新系の関数（`fv normalize` のエラー `formula.update`。「使う」がオフの行でも）: `FSET`, `FSET_TADD`, `BUTTON`, `DIALOG`, `CLIPBORD_WRITE`, `EV_SET`, `TLTABLE`, `TABLE_SORT`, `TABLE_MAP`, `TABLE_DATA`, `CSV_TVAL`
- 保存のとき、式の `//` から行末までと改行が消える（文字列の中も）。`"https://…"` のような文字列は切れて式が壊れる
- 式は表示・値の変更・保存の前・一覧の編集のたびに評価される。`TODAY` / `NOW` / `RAND` などは評価のたびに変わる（警告 `formula.volatile`）

## 扱う版

- 設定: 項目検証 Ver.72 以降（取り込み方「全置換 / 項目の置換」と元の値の形が Ver.72 から）
- 式の評価: 計算式プラグインの zip Ver.102 以降（試用版でよい）。項目検証の版に同梱のエンジンと違えば、情報 `engine.differs` を出して続ける

| 項目検証 | 同梱のエンジン（計算式の版） |
| --- | --- |
| Ver.72 | 計算式 Ver.102（engine sha256 `023c3504afd4…`） |
