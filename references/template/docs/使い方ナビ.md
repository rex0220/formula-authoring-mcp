## 2. 使い方の流れ

1. **はじめに**: 状態を確かめる（作業フォルダー、計算式プラグインの zip、kintone の接続）。足りないものは利用者が設定する
2. **新しい計算式**: アプリの番号 → 項目を取る → 確かめに使う代表のレコード → 仕様の確認（分からない所は AI が聞く）→ 式を書いて保存（検査を通る）→ 模擬の計算で値を確かめる → 反映
3. **アプリがまだ無い・式の動きだけ確かめたい**: 同梱のサンプルアプリ（架空の値）で試し計算する。項目・要件・テストデータを書いて頼むと、試し計算で確かめた式を返す。サンプルアプリの項目は利用者のアプリのものではないので、設定にするときは利用者のアプリの項目で書き直す
4. **今の計算式を変える・解説してほしい**: 4 章
5. **反映**: 設定画面で **設定をアップロード** → 取り込み方を選ぶ（設定がまだ無いアプリは **全置換**、項目を足す・変えるなら **項目の置換** で対象の項目にチェック）→ 保存 → 運用環境に反映。**保存しても既存のレコードの値は変わらない**。値を計算する項目を変えたら、既存のレコードは「既存レコードを変更」か一覧の「一括計算」で計算し直す（ボタン・表示だけの変更なら要らない）

## 3. 頼み方（新しい計算式）

伝えるとよいこと（分からなければ AI が聞く）:

- アプリの番号（かアプリの URL）。どの環境（開発・本番）のアプリか
- 計算したい項目と、計算の決まり（例: 金額 = 単価 × 数量、消費税は課税の明細だけ 10%）。テーブルの中か外か
- 端数の扱い（四捨五入・切り捨て）、空のとき・0 のときにどうするか
- いつ計算するか（保存のとき、画面を開いたとき、ボタンを押したとき）
- 既存のレコードも計算し直すか

例:


## 4. 今の計算式を変える・解説してもらう

流れ:

1. **今の設定を作業フォルダーに置く**: kintone の API ラボ（プラグインの設定情報を取得する API）を有効にした環境なら AI が取る（pull）。取れなければ、利用者が計算式プラグインの設定画面の「設定をダウンロード」で保存した JSON を作業フォルダーの `inbox/`（接続のファイルがあるとき）か `settings/` に置く
2. **AI が写しを直す**: ダウンロード・pull したファイルは書き換えず、写し（`-edit.json`）を直す。頼まれていない項目の行は変えない
3. **差分を見る**: 変える前と後の差を利用者が確かめる（★ は値を計算する項目が変わった行）
4. **模擬の計算**: 代表のレコードで値を確かめる（kintone のレコードは更新しない）
5. **反映**: 設定画面でアップロードし、取り込み方は **項目の置換**（変えた項目だけチェック。共通の設定を変えていなければ「共通の設定」のチェックを外す）。★ があれば既存のレコードは「既存レコードを変更」か「一括計算」で

例（記事で実際に使ったもの）:

```
計算式プラグインで、アプリ 4330 の分類集計の行を、分類の名前順でなく分類金額の大きい順にして
```

```
計算式プラグインで、アプリ 4330 の分類金額の計算式を解説して
```

```
（設定画面からダウンロードした設定のファイルを添付して）
計算式を解説して
```

```
計算式プラグインの DIC 関数について解説して
```

伝えるとよいこと: どのアプリのどの項目か、変えたい計算と変えた後の結果、確かめに使うレコード。変えたくない所があれば添える。

## 5. AI がしないこと・利用者がすること

- AI は kintone に書き込まない。設定の反映（アップロード → 保存 → 運用環境に反映）と、既存のレコードの計算し直し（既存レコードを変更・一括計算）は利用者。例外は、利用者が告げたテスト用アプリへのテストデータの追加と、利用者が「新しいアプリを作って」と明示したときだけ
- 一覧 ID、権限のユーザー・組織・グループのコード、ルックアップ先は推測しないので、聞かれたら利用者が伝える
- kintone の接続のファイルとトークンは利用者が設定する（AI は読まない・書かない）
- 副作用のある関数（FSET / FSET_TADD / BUTTON / DIALOG / CLIPBORD_WRITE）を使う式と、イベントで結果が変わる式（EV_INFO）は、その旨を AI が伝える。ボタンの押した後の値は模擬で確かめ、最後は利用者が実機で押して確かめる
- 試し計算と模擬の計算は架空の値（ユーザー情報は既定のテストデータ）。実際の値での結果は、利用者がレコードの画面で確かめる
