# 設定ファイル仕様（AI が書く元の値 FormulaSource の封筒）

計算式プラグイン Ver.101（authoring API 1、設定スキーマの版 6ecd050f90d4）の `CONFIG_SCHEMA` から `tools/scripts/gen-docs.mjs` が作る。手で直さない。

## 封筒

設定画面の「ダウンロード」と同じ形。`pull` と `normalize --out` もこの形で書く。`date` と `appName` は表示用。

| キー | 値 |
| --- | --- |
| `pluginID` | `"rex0220 formula plugin"`（固定） |
| `PluginVersion` | `"101"`（zip の版。古い版の設定も取り込める） |
| `appId` | アプリ番号（正の整数。fields のアプリと同じ） |
| `appName` / `date` | 表示用 |

## pluginInfos の 1 行（項目ごとの設定）

| キー | 意味 |
| --- | --- |
| `fieldcode` | 項目のフィールドコード（ラベルではない。`fields --summary` の ○ の型だけ） |
| `state` | 計算する（true）。false なら計算式があっても計算しない |
| `formulaSet` | 計算式（`//` から行末まではコメント。改行は実行時に無視。文字列の中の `//` もコメントになる） |
| `edit` | 画面で編集できる（既定 false。計算式が入れた値を利用者が直せる） |
| `hide` | 画面で非表示（既定 false） |
| `rank` | 計算の順（整数 -10000〜10000。**大きい順**に計算。`""` は 0。同じならレイアウトの順 = テーブルの外の項目（1 回目）: 上から下、同じ行では左から右 → テーブルの中の項目: 左から右 → テーブルの外の項目（2 回目）: 上から下、同じ行では左から右。この順で合うならランクは付けない。参照される項目が後ろにあるときだけ、その項目に参照する項目より**大きい**ランクを付ける） |

計算式を設定できる型: GROUP, SUBTABLE, MULTI_LINE_TEXT, SINGLE_LINE_TEXT, RICH_TEXT, NUMBER, DATE, DATETIME, TIME, DROP_DOWN, RADIO_BUTTON, CHECK_BOX, MULTI_SELECT, GROUP_SELECT, ORGANIZATION_SELECT, USER_SELECT, LINK

## 各種設定（pluginMiscInfo）の既定

| キー | 既定 |
| --- | --- |
| `circular_refer` | false |
| `async` | true |
| `userInfo` | true |
| `calcStep1` | true |
| `calcTable` | true |
| `calcStep2` | true |
| `tableCalcSkip` | false |
| `eventCreateShow` | true |
| `eventEditShow` | true |
| `eventCreateChange` | true |
| `eventEditChange` | true |
| `eventCreateSubmit` | true |
| `eventEditSubmit` | true |
| `eventCreateSuccess` | true |
| `eventEditSuccess` | true |
| `eventProcess` | true |

既定から変えると `normalize` が警告する（利用者が決めること。policy の `allowMiscChanges`）。`circular_refer` は循環参照を許す、`userInfo` は UINFO 系の関数を使う、`async` は値変更イベントの非同期計算。

## ボタン（pluginBtnInfo）の既定

```json
{
  "detail_btn": {
    "state": false,
    "default": "計算",
    "ja": "",
    "en": "",
    "zh": ""
  },
  "list_btn": {
    "state": false,
    "default": "一括計算",
    "ja": "",
    "en": "",
    "zh": ""
  }
}
```

`detail_btn`（詳細画面の「計算」）、`list_btn`（一覧の「一括計算」）。`state` で出す。`ja` / `en` / `zh` が空なら `default`。

## 書かないキー（派生値・外枠）

派生値（設定画面が保存時に作り直す。tools は捨てる）: `pluginFields`, `pluginPP`, `tableTrigger`, `pluginRecNo`, `pluginModifier`, `pluginStatus`, `pluginStatusCode`, `pluginStatusAssignee`, `pluginHide`, `pluginLookup`, `pluginUOG`

画面の行のキー（捨てる）: `id`, `row_type`, `type`, `fieldlabel`, `fieldno`, `tableno`, `tablepos`, `message`, `ptcode`, `usedFields`, `width`, `formula`
