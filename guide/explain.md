# 計算式の解説を頼まれたら

AI が作った設定でも、設定画面からダウンロードした既存の設定（`inbox/` → `fml_take`、`fml_pull`、`settings/` に置いたもの）でもよい。

1. `fml_summary`（path）で項目の一覧（ランク順 = 計算順）を、`field` で解説する項目の計算式の全文を見る（設定ファイルそのものを Read で開かない）。項目の型と選択肢は `fml_fields` の要約（取り直すか、`fml_files` で fields.json があることを確かめる）
2. 使っている関数の引数と意味は function-list の章（`fml_docs` の query に関数名）で確かめ、定型のやり方なら patterns の章のパターン名で言う
3. 説明に入れること: 何を計算するか（1〜2 行）、テーブルの行ごとに動くか外で動くか、計算順（ランクなしの順で合っているか）、変数（LET）の意味、条件ごとの値（例: 明細 / 小計 / それ以外）、空・未選択・該当なし・0 件のときの値、印（副作用のある関数、イベントで変わる、再計算のたびに変わる、ユーザー情報・kintone の文脈に依る）、気づいた問題（順が逆、空の扱いが無い、テストのレコードに無い値）
4. 必要なら `fml_record` → `fml_calc` で、そのレコードに当てた実際の値を添える（模擬。更新しない）
5. 分からない点（意図、アプリの運用）は推測せず「確かめたいこと」として書く
